# ペルソナファイルのフィールド仕様

本ドキュメントでは、ペルソナ JSON ファイル（`agent_a.json`, `agent_b.json`）の各フィールドがシステム内でどのように使用されているかを説明します。

---

## フィールド一覧

| フィールド        | 必須          | 型     | 使用状況                 |
| ----------------- | ------------- | ------ | ------------------------ |
| `name`            | ✅ 必須       | string | 発話者識別に使用         |
| `persona_summary` | ✅ 必須       | string | 発話生成プロンプトに使用 |
| `msc_prompt`      | ❌ オプション | string | **現在未使用**           |
| `speaking_style`  | ❌ オプション | string | **現在未使用**           |
| `age`             | ❌ オプション | number | **現在未使用**           |
| `gender`          | ❌ オプション | string | **現在未使用**           |
| `occupation`      | ❌ オプション | string | **現在未使用**           |
| `interests`       | ❌ オプション | array  | **現在未使用**           |
| `notes`           | ❌ オプション | string | **現在未使用**           |

---

## 詳細説明

### `name` （必須）

**用途**: エージェントの識別名

**使用箇所**:

- 発話生成プロンプトの話者名として使用
- 会話ログの話者ラベル
- 関係値内省プロンプトの主体/対象として使用
- ファクト抽出時のキー名

**例**:

```json
"name": "ドラえもん"
```

**プロンプトでの使用例**:

```
ドラえもん は のび太 と会話します。今日は 15 April, 2022 です。
あなたは ドラえもん になりきり、のび太 に対して次に言う一言を書いてください。
```

---

### `persona_summary` （必須）

**用途**: キャラクターの性格・背景を説明するテキスト

**使用箇所**:

1. **発話生成プロンプト**: プロンプト冒頭にペルソナとして挿入
2. **関係値内省プロンプト**: `src_persona`, `dst_persona` として使用
3. **メモリ検索クエリ**: ペルソナ文をクエリとして使用可能
4. **トランスクリプト出力**: ペルソナ説明として表示

**例**:

```json
"persona_summary": "22世紀の未来から来たネコ型ロボット。のび太の世話係として送り込まれた。使命感は強いが、おっちょこちょいで世話焼き。どら焼きが大好物。"
```

**プロンプトでの使用例**:

```
22世紀の未来から来たネコ型ロボット。のび太の世話係として送り込まれた。
使命感は強いが、おっちょこちょいで世話焼き。どら焼きが大好物。

ドラえもん は のび太 と会話します。...
```

**関係値内省での使用例**:

```
キャラクターのペルソナ:
- ドラえもん: 22世紀の未来から来たネコ型ロボット...
- のび太: 小学5年生の男の子。勉強もスポーツも苦手で...
```

---

### `msc_prompt` （オプション・現在未使用）

**用途**: ロールプレイ指針（MSC: Multi-Session Chat 由来）

**現状**: コードに読み込み処理はあるが、発話生成には使用されていない

**例**:

```json
"msc_prompt": "ロールプレイ指針：保護者のような視点で接する。相手が怠惰な時は叱咤激励し、本当に困っている時は道具を提案して助ける。"
```

**活用案**: `persona_summary` に統合するか、将来的に独自のプロンプトセクションとして使用

---

### `speaking_style` （オプション・現在未使用）

**用途**: 話し方の特徴

**現状**: JSON に含めることは可能だが、発話生成に直接反映されない

**例**:

```json
"speaking_style": "親しみやすく、保護者的。時に厳しく説教をするが、基本的には甘い。「〜だよ」「〜だね」という語尾が多い。"
```

**活用案**: `persona_summary` に含めるのが現時点での推奨方法

---

### `age`, `gender`, `occupation` （オプション・現在未使用）

**用途**: キャラクターの基本属性

**現状**: JSON に含めることは可能だが、発話生成に直接反映されない

**例**:

```json
"age": 12,
"gender": "male",
"occupation": "子守り用ロボット"
```

**活用案**: これらの情報は `persona_summary` に自然言語で含めることを推奨

---

### `interests` （オプション・現在未使用）

**用途**: キャラクターの興味・趣味

**現状**: JSON に含めることは可能だが、発話生成に直接反映されない

**例**:

```json
"interests": [
  "どら焼き",
  "ミイちゃん（近所の猫）とのデート",
  "のび太の世話"
]
```

**活用案**: `persona_summary` に自然言語で含めることを推奨

---

### `notes` （オプション・現在未使用）

**用途**: 追加のキャラクター情報

**現状**: JSON に含めることは可能だが、発話生成に直接反映されない

**例**:

```json
"notes": "一人称は「ぼく」。二人称は「きみ」または「のび太くん」。四次元ポケットから未来の「ひみつ道具」を出すことができる。"
```

**活用案**: `persona_summary` に含めることを推奨

---

## 推奨されるペルソナ構成

現在の実装では、`name` と `persona_summary` のみが発話生成に影響します。
そのため、他のフィールドの情報は `persona_summary` に統合することを推奨します。

### 最小構成（必須フィールドのみ）

```json
{
  "name": "ドラえもん",
  "persona_summary": "22世紀の未来から来たネコ型ロボット。のび太の世話係として送り込まれた。使命感は強いが、おっちょこちょいで世話焼き。どら焼きが大好物。一人称は「ぼく」。親しみやすく、保護者的な話し方をする。"
}
```

### 拡張構成（メタデータ保持）

将来の拡張や人間の可読性のために、オプションフィールドを残すことも可能です。

```json
{
  "name": "ドラえもん",
  "persona_summary": "22世紀の未来から来たネコ型ロボット。のび太の世話係として送り込まれた。使命感は強いが、おっちょこちょいで世話焼き。どら焼きが大好物。一人称は「ぼく」。親しみやすく、保護者的な話し方をする。",
  "age": 12,
  "gender": "male",
  "occupation": "子守り用ロボット",
  "speaking_style": "親しみやすく、保護者的。「〜だよ」「〜だね」という語尾が多い。",
  "interests": ["どら焼き", "のび太の世話"],
  "notes": "ネズミが極端に苦手で、遭遇すると理性を失う。"
}
```

## 実行時に自動追加されるフィールド

会話生成の実行中に、以下のフィールドがエージェント JSON に自動追加されます：

| フィールド                          | 説明                                 |
| ----------------------------------- | ------------------------------------ |
| `session_N`                         | セッション N の会話ログ              |
| `session_N_date_time`               | セッション N の日付                  |
| `session_N_summary`                 | セッション N の要約                  |
| `session_N_topic`                   | セッション N のテーマ                |
| `session_N_facts`                   | セッション N で抽出されたファクト    |
| `session_N_relationship_reflection` | セッション N の関係値内省結果        |
| `memory_stream`                     | メモリストリーム（発話・内省の履歴） |

# 内省妥当性評価（Reflection Validity Evaluation）

## 概要

このディレクトリには、**関係値内省（Relationship Reflection）の妥当性**を評価するためのスクリプトが含まれています。

内省とは、エージェントが会話履歴を振り返り、相手との関係値（Power, Intimacy, TaskOriented）がどのように変化したかを自己評価するプロセスです。本評価では、その内省結果が会話内容に対して妥当であるかを **LLM as a Judge** 手法で定量化します。

## 評価手法：LLM as a Judge

### なぜ LLM as a Judge か？

内省の妥当性評価には以下の課題があります：

1. **シナリオ意図との不一致**：「親密度を上げる」シナリオでも、生成された会話が意図通りにならない場合がある
2. **イベント品質への依存**：イベント設計の質によって内省結果が変わる
3. **人間評価のコスト**：大量のサンプルを人手で評価するのは非現実的

**解決策**：別の LLM（Judge）に「会話内容を見て、この関係値変化は妥当か？」を判定させることで、イベント設計の質を考慮した公平な評価が可能になります。

### 評価プロセス

```
┌─────────────────────────────────────────────────────────────┐
│  入力データ（relationship_reflection_details.jsonl）          │
│  ├─ prompt: 内省時に使用したプロンプト                         │
│  │   ├─ 前回の関係値                                         │
│  │   └─ 根拠となる会話履歴                                    │
│  └─ generated_values: 内省結果 {Power, Intimacy, TaskOriented}│
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  抽出処理                                                    │
│  1. 前回の関係値を抽出                                        │
│  2. 会話履歴（根拠）を抽出                                     │
│  3. 内省結果から変化量を計算                                   │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  LLM Judge による判定                                        │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ 評価観点:                                            │    │
│  │ 1. 変化の方向は会話内容と一致しているか                │    │
│  │ 2. 変化の大きさは妥当か（急激すぎないか）              │    │
│  │ 3. キャラクターの性格を考慮した解釈として適切か        │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  出力スコア                                                  │
│  ├─ overall_validity: 総合妥当性 (1-5)                       │
│  ├─ power_validity: Power変化の妥当性 (1-5)                  │
│  ├─ intimacy_validity: Intimacy変化の妥当性 (1-5)            │
│  └─ task_validity: TaskOriented変化の妥当性 (1-5)            │
└─────────────────────────────────────────────────────────────┘
```

## 評価スコアの解釈

| スコア | 意味       | 説明                           |
| :----: | ---------- | ------------------------------ |
|   5    | 非常に適切 | 会話内容から自然に導かれる変化 |
|   4    | 適切       | 会話内容と整合的な変化         |
|   3    | 妥当       | 変化の解釈として許容範囲       |
|   2    | やや不適切 | 会話内容との関連が弱い         |
|   1    | 不適切     | 会話内容と矛盾する変化         |

## 使用方法

### 前提条件

```bash
source scripts/env.sh  # Gemini API キーの設定
```

### 単一シナリオの評価

```bash
python3 evaluation_reflection/evaluate_reflection_validity.py \
    --data-dir out/eva_intimacy_increase \
    --sample-size 10 \
    -v
```

### 全シナリオの評価

```bash
python3 evaluation_reflection/evaluate_reflection_validity.py \
    --data-dir out \
    --all-scenarios \
    --sample-size 20
```

### 関係値注入あり/なしの比較

```bash
python3 evaluation_reflection/evaluate_reflection_validity.py \
    --data-dir out \
    --compare-injection \
    --sample-size 10
```

## オプション

| オプション            | 説明                            | デフォルト |
| --------------------- | ------------------------------- | ---------- |
| `--data-dir`          | 評価対象のディレクトリ          | 必須       |
| `--sample-size`       | 評価するサンプル数              | 全件       |
| `--all-scenarios`     | data-dir 配下の全シナリオを評価 | False      |
| `--compare-injection` | 注入あり/なしを比較             | False      |
| `-v, --verbose`       | 詳細出力                        | False      |

## 関連評価との比較

本研究では 3 種類の評価を実施しています：

| 評価名             | ディレクトリ                | 評価対象                           | 手法                   |
| ------------------ | --------------------------- | ---------------------------------- | ---------------------- |
| 逆推定評価         | `evaluation_style/`         | 発話に関係値が反映されているか     | 発話から関係値を逆推定 |
| **内省妥当性評価** | `evaluation_reflection/`    | 内省結果が会話内容と整合しているか | LLM as a Judge         |
| シナリオ整合性評価 | `introspection_evaluation/` | 内省結果がシナリオ意図と一致するか | 変化方向の比較         |

## 実験結果（参考）

| 条件           | 内省妥当性 |
| -------------- | ---------- |
| 関係値注入あり | 4.23/5     |
| 関係値注入なし | 4.17/5     |

→ 両条件とも高い妥当性を示し、内省プロセス自体が適切に機能していることを確認
